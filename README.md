# بوابة معرفة

منصة قانونية إلكترونية تجمع الأنظمة السعودية وتحديثاتها التشريعية، مع أدوات عملية (حاسبات قانونية) تخدم المحامين والشركات والأفراد.

هذه هي **المرحلة الأولى (MVP)**: الأساس التقني الكامل مبني، بمحتوى قانوني عبارة عن بيانات عيّنة توضيحية محدودة (وليست نسخة رسمية معتمدة)، لحين استكمال التواصل مع الجهات الرسمية للحصول على وصول API لبياناتها.

## التقنية المستخدمة

- Laravel 11 + PHP 8.5
- Blade + Livewire 3 (تفاعلية بدون تعقيد SPA)
- Tailwind CSS 3 مهيّأ بالكامل لاتجاه RTL وخط Tajawal العربي
- Filament v3 كلوحة إدارة للمحتوى
- SQLite للتطوير المحلي (بدون أي إعداد) → يمكن التحويل لـ MySQL في الإنتاج عبر متغيرات `.env` فقط
- `laravel-lang/lang` (تبعية تطوير فقط) استُخدمت لتوليد ترجمات عربية لواجهات المصادقة والتحقق (`lang/ar.json`, `lang/ar/*.php`)

## التشغيل محليًا

```bash
composer install
npm install && npm run build   # أو: npm run dev أثناء التطوير
php artisan migrate:fresh --seed
php artisan make:filament-user   # لإنشاء مستخدم لوحة الإدارة إن لم يكن موجودًا
php artisan serve
```

- الموقع العام: `http://localhost:8000`
- لوحة الإدارة: `http://localhost:8000/admin`

بيانات الدخول الافتراضية للوحة الإدارة (تم إنشاؤها أثناء البناء، غيّرها فور النشر):
- البريد: `admin@marefa.local`
- كلمة المرور: `password123`

## ما هو مبني في هذه المرحلة

- فهرس الأنظمة مع بحث وتصفية حسب التصنيف والحالة (نافذ / معلق النفاذ / ملغى)
- صفحة تفصيلية لكل نظام بمواده وتحديثاته المرتبطة
- صفحة "آخر التحديثات التشريعية"
- حاسبة مكافأة نهاية الخدمة (Livewire) وفق نظام العمل السعودي (المواد ٨٤-٨٥)
- تسجيل/دخول بالبريد وكلمة المرور (Laravel Breeze) ونظام مفضّلة للأنظمة
- لوحة إدارة (Filament) لإدارة الأنظمة ومواده والتصنيفات والتحديثات، بدون الحاجة لكتابة كود لإضافة محتوى جديد

## نموذج البيانات جاهز للربط المستقبلي بـ API رسمي

جدول `law_entries` يحتوي على حقلي `source_url` و`external_id` مخصصين للربط لاحقًا بمصدر بيانات رسمي (بعد الحصول على وصول API من الجهات المعنية)، دون الحاجة لإعادة هيكلة قاعدة البيانات — فقط إضافة أمر/مهمة استيراد (import job) تعبئ هذه الجداول بدل الإدخال اليدوي عبر لوحة Filament.

## خارج نطاق هذه المرحلة (مخطط لاحقًا)

- التحقق عبر OTP/SMS بدل البريد وكلمة المرور
- ربط API حكومي حقيقي (بانتظار الوصول من الجهات الرسمية)
- بحث ذكي بالذكاء الاصطناعي على نصوص الأنظمة
- مولّد عقود، تتبع قضايا، نسخة إنجليزية، تنبيهات واتساب عند صدور تحديثات
- النشر على استضافة الإنتاج (Hostinger) بعد استبدال المحتوى التجريبي ببيانات حقيقية
